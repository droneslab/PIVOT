# PIVOT project page deployment

Copy `index.html` and `static/` into the root of `droneslab/PIVOT`, and replace the repository `README.md` with this package's `README.md`.

The project page and README use the existing `Fov demo.gif` from the PIVOT GitHub repository via its raw GitHub URL. All paper figures used by the website are included under `static/images/`.

For GitHub Pages, publish the `main` branch from `/ (root)`.
